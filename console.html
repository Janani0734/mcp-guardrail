Approve AI agent actions before they execute.

MCP-Guardrail turns risky AI tool calls into expiring, human-approved requests. Your AI can request an action but a person decides whether it happens.

Your AI agent can ask. You decide.

What it prevents

  • Unapproved file or database deletions
  • Automatic emails, payments, and cloud changes
  • Irreversible actions from autonomous agents
  • Missing approval history for AI decisions
Current release is a developer preview using disposable sandbox data. It is not a certified enterprise security product.
